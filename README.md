# Public CVE Disclosures

## About This Repository  
This repository contains publicly disclosed Common Vulnerabilities and Exposures (CVEs) that I have reported. Each CVE entry includes details such as the affected software, vulnerability description, proof-of-concept (PoC) exploits (if applicable), and remediation recommendations.

## Disclaimer  
All vulnerabilities shared here have been responsibly disclosed to the affected vendors before publication. The purpose of this repository is to contribute to the security community by raising awareness and helping organizations mitigate risks.  

**Use this information responsibly.** Unauthorized exploitation of vulnerabilities is illegal and unethical.
